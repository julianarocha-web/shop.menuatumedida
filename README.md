# Menú a tu Medida - Viandas Saludables 🥗

## 📋 Sobre el Proyecto
**Menú a tu Medida** es una plataforma de e-commerce diseñada para facilitar la planificación alimentaria semanal. El proyecto nace de la necesidad de ofrecer viandas caseras, saludables y personalizadas para personas que buscan optimizar su tiempo sin descuidar su nutrición.

Este sitio permite a los usuarios explorar platos destacados, navegar por categorías (Desayunos, Almuerzos, Meriendas y Cenas) y gestionar sus pedidos a través de un carrito de compras interactivo.

---

## 🛠️ Tecnologías y Herramientas
Para el desarrollo de este sitio se utilizaron:

- **HTML5:** Estructura semántica avanzada para SEO y accesibilidad.
- **CSS3:** Estilos personalizados y diseño responsivo.
- **Bootstrap 5:** Framework para el layout (Grid, Navbar, Offcanvas, Modales).
- **Animate.css:** Animaciones para mejorar la experiencia de usuario (UX).
- **Git & GitHub:** Control de versiones y despliegue a través de GitHub Pages.
- **Figma:** Diseño previo de la interfaz y prototipado.

---

## 🚀 Optimizaciones SEO 
El sitio fue optimizado siguiendo los criterios fundamentales de posicionamiento orgánico:

- **SEO Técnico:** Implementación de archivos `robots.txt` y `sitemap.xml` en la raíz del proyecto.
- **Estructura Semántica:** Uso jerárquico de etiquetas de encabezado (`h1`, `h2`, `h3`) y etiquetas de sección.
- **Metadatos:** Configuración de `title` optimizado, `description` estratégica y etiquetas `meta-robots`.
- **Accesibilidad:** Inclusión de atributos `alt` descriptivos en todas las imágenes y nombres de archivos optimizados.
- **Performance:** Diseño Responsive y optimización de recursos.

---

## ✨ Funcionalidades Principales
- **Navegación Intuitiva:** Menú responsive con acceso rápido a las secciones de la tienda.
- **Tienda Interactiva:** Selección de viandas por momentos del día.
- **Gestión de Cantidades:** Sistema de steppers para definir porciones por plato.
- **Carrito de Compras:** Panel lateral (Offcanvas) para revisar y gestionar el pedido antes de finalizar.
- **Formulario de Registro:** Sección para captación de usuarios con validaciones de campos.
